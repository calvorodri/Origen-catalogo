# Catálogo Origen — Consumo Natural

Sitio web del catálogo digital, con carrito y pedido por WhatsApp.

## Cómo actualizar
1. Descargar el archivo HTML actualizado.
2. Entrar a este repositorio → tocar index.html.
3. Tocar el ícono de lápiz (editar).
4. Reemplazar todo el contenido, o subir el archivo nuevo con el mismo nombre (index.html).
5. Confirmar con "Commit changes".
6. Vercel actualiza la página sola en unos segundos.

URL en vivo: https://origen-catalogo.vercel.app
